# openGym exercise text data

`opengym-exercises.zh.json` is generated from the non-media portion of
[`hasaneyldrm/exercises-dataset`](https://github.com/hasaneyldrm/exercises-dataset),
the exercise data source used by openGym.

The upstream project releases its code, dataset structure, exercise metadata,
and multilingual instruction text under the MIT License. The generated file in
this repository contains only names, classifications, equipment metadata, and
Chinese instruction text.

No image or animation from that dataset is included. Upstream exercise media is
separately owned by Gym visual and is not covered by the dataset's MIT License.
The technique frames already under `public/exercise-media/free-exercise-db`
continue to come from the public-domain `free-exercise-db` project.
